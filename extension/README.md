# Cognivue Extension — Browser Focus Companion

This directory serves as the future home of the Manifest V3 Cognivue browser companion.

## Planned Tech Stack
- **Framework**: TypeScript + HTML/CSS Popup UI
- **Standard**: Chrome Extensions Manifest V3
- **Communication Layer**: Native runtime messaging to the Cognivue desktop dashboard client

## Planned Features
1. **Active Tab Tracker**: Computes active browsing times on academic, engineering, and distraction-oriented domains.
2. **Scroll Telemetry**: Gathers page scroll speed indicators to alert the inference engine of reading fatigue.
3. **Session Interrupter**: Soft-shields distraction sites when the client reports high cognitive load or burnout risk.
